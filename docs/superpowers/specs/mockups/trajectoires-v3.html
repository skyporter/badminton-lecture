Le code des trajectoires (vue de dessus)

Deux règles seulement : le pointillé dit la vitesse (plus c'est espacé, plus c'est lent) et la courbe dit la hauteur (courbe = volant envoyé haut, droit = à plat ou descendant). Même code pour le coup de B (orange) et pour ton retour (jaune).
